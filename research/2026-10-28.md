### 2. Masih pakai password biasa di aplikasi web-mu? Saatnya beralih ke Passkey! _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Menjelaskan keuntungan teknis Passkey berbasis WebAuthn untuk menggantikan password tradisional yang rentan phishing dan credential stuffing.

**Slide-by-slide:**
1. **Kenapa Password Mulai Ditinggalkan?** — Password memaksa user mengingat rahasia yang rentan di-phish dan di-reuse. Bagi developer, mengelola password hash dan penanganan kebocoran data menjadi beban besar.
2. **Apa Itu Passkey & WebAuthn?** — Passkey menggunakan Kriptografi Kunci Publik berbasis standar WebAuthn. Private key tersimpan aman di perangkat user (dikunci sidik jari/wajah), sedangkan public key disimpan di server.
3. **Keunggulan Utama Passkey** — Passkey secara alami kebal terhadap phishing karena browser memvalidasi domain secara ketat. Selain itu, tidak ada shared secret yang dikirimkan saat proses login.
4. **Stack Praktis: Next.js + NestJS** — Kamu bisa membangun passkey auth menggunakan Next.js di frontend dan NestJS + PostgreSQL di backend. Gunakan library TypeScript SimpleWebAuthn untuk mempermudah integrasi.
5. **Mulai Buat Aplikasimu Lebih Aman** — Dengan mengimplementasikan WebAuthn, kamu menghilangkan risiko credential stuffing sekaligus memberikan pengalaman login yang jauh lebih praktis untuk penggunamu.
