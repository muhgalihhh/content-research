**Slide-by-slide:**
1. **Kelemahan Password Tradisional** — Password rawan terhadap serangan phishing, credential stuffing akibat password reuse, dan membebani developer dalam pengelolaan hash serta rate limit.
2. **Solusi Lewat Passkeys** — Passkeys menghapus rahasia bersama (shared secret). Pengguna cukup konfirmasi identitas pakai sidik jari, pemindaian wajah, atau PIN di perangkat mereka.
3. **Arsitektur Teknologi** — Backend menggunakan NestJS API yang menyimpan data di PostgreSQL, dipadukan dengan frontend Next.js dan pustaka SimpleWebAuthn.
4. **Keamanan Berbasis WebAuthn** — Kunci privat tersimpan aman di perangkat pengguna, sementara kunci publik dikirim ke website untuk verifikasi kriptografi yang anti-phishing.
