### 1. VSCode Remote SSH Bikin Kamu Bingung? Ini Dia Penyebabnya! _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Banyak developer pakai Remote-SSH di VSCode, tapi seringkali ada masalah koneksi atau permission yang bikin pusing. Konten ini akan menjelaskan akar masalahnya, terutama soal SSH Agent.

**Slide-by-slide:**
1. **VSCode Remote SSH & Misteri SSH Agent** — Pernah ngalamin SSH koneksi di VSCode tiba-tiba gak bisa atau minta password berkali-kali? Kamu gak sendirian! Seringkali, biang keroknya ada di SSH Agent.
2. **Apa Itu SSH Agent?** — SSH Agent adalah program di balik layar yang menyimpan private key SSH kamu di memori. Tujuannya? Biar kamu gak perlu masukkin passphrase terus-terusan saat konek ke server remote. Praktis, kan?
3. **Kenapa VSCode Perlu SSH Agent?** — Saat kamu pakai Remote-SSH, VSCode perlu akses ke server remote. Daripada tiap kali disuruh autentikasi, dia 'meminjam' kredensial dari SSH Agent yang sedang berjalan.
4. **Masalah Umum: 'Agent Tidak Ditemukan'** — Terkadang, VSCode gagal menemukan SSH Agent yang aktif. Ini bisa terjadi kalau agent belum jalan, atau VSCode pakai lingkungan shell yang berbeda. Solusinya? Pastikan agent kamu running dan environment variabelnya benar.
5. **Tips: Cek Status SSH Agentmu** — Di terminal, coba jalankan `ssh-add -l`. Kalau ada error, berarti agent belum jalan. Kalau menampilkan daftar key, berarti agent aktif. Jika belum, start dengan `eval "$(ssh-agent -s)"` dan `ssh-add ~/.ssh/id_rsa`.
6. **Solusi Praktis untuk Koneksi Lancar** — Pastikan private key SSH kamu ditambahkan ke agent. Untuk pengguna Linux/macOS, coba tambahkan `AddKeysToAgent yes` di `~/.ssh/config` supaya key otomatis ditambahkan saat pertama kali pakai.
7. **Auto-Start SSH Agent di Startup** — Agar SSH Agent selalu siap, konfigurasikan shell kamu (misal: `.bashrc`, `.zshrc`) untuk memulai SSH Agent secara otomatis saat login. Banyak panduan tersedia online untuk setup ini.

### 2. Lupakan Media Queries! Saatnya #ContainerQueries CSS Bikin UI Makin Responsif! _(Format: Story — konten cepat & spontan, cocok quick tips/teaser, otomatis hilang dalam 24 jam)_

**Angle:** Container Queries adalah game-changer untuk membuat komponen UI yang benar-benar responsif, terlepas dari ukuran viewport keseluruhan. Ini adalah quick dive into the concept.

**Slide-by-slide:**
1. **Kenalan sama Container Queries!** — Bosan dengan Media Queries yang hanya responsif pada viewport? Ada cara baru! #ContainerQueries bikin komponenmu cerdas dan responsif pada ukuran kontainernya sendiri.
2. **Bedanya dengan Media Queries?** — Media Queries cek ukuran browser. Container Queries? Cek ukuran elemen induknya! Jadi, satu komponen bisa adaptasi di mana pun dia diletakkan, tanpa tergantung ukuran layar total. Keren kan?
3. **Contoh: Komponen Kartu Responsif** — Bayangkan kartu produk. Di sidebar, dia bisa jadi kecil. Di halaman utama, dia membesar. Dengan Container Queries, kamu atur style kartu itu sendiri, bukan halaman tempatnya berada.
4. **Syntax Dasar @container** — Cukup pakai `@container (min-width: 400px) { ... }`. Definisikan `container-type` dan `container-name` di parent, lalu style elemen di dalamnya. Simpel!
5. **Kenapa Ini Penting untuk Design System?** — Dengan Container Queries, komponen-komponenmu jadi lebih fleksibel dan reusable. Bangun sekali, pakai di mana saja dengan layout yang adaptif. Mantap buat Design System!
6. **Siap Coba di Projectmu?** — Fitur ini sudah didukung browser modern. Jadi, tunggu apa lagi? Mulai explore #ContainerQueries sekarang! #CSS #UIUX #WebDev
