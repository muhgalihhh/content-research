### 1. Sering nemu error SSL certificate error saat jalankan Claude Code atau npm di Mac kantor? _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Menjelaskan kenapa fitur keamanan kantor (SWG) bikin tools CLI dev error certificate validation dan cara mengatasinya secara aman tanpa NODE_TLS_REJECT_UNAUTHORIZED=0.

**Slide-by-slide:**
1. **Kenapa Claude Code & npm Bikin SSL Error?** — Paling sebal kalau Safari atau Chrome bisa lancar membuka api.anthropic.com, tapi CLI dev seperti Claude Code, Cursor, atau npm install malah mental gara-gara SSL certificate error di Mac kantor.
2. **Penyebab Utamanya** — Ini terjadi karena Corporate Secure Web Gateway (SWG) seperti Zscaler, Netskope, atau Cloudflare Zero Trust mengintercept TLS dan re-sign sertifikat dengan Root CA internal perusahaan.
3. **Jangan Pakai Cara Instan!** — Menggunakan NODE_TLS_REJECT_UNAUTHORIZED=0 sangat berbahaya. Mengabaikan verifikasi TLS secara global mematikan enkripsi API key dan OAuth token di jaringan mana pun.
4. **Solusi Bersih macOS** — Solusi bersihnya adalah mengeksport corporate Root CA dari Keychain macOS dan menggabungkannya dengan bundle CA bawaan system agar domain publik dan internal terverifikasi lancar.
5. **Set Environment Variable** — Tambahkan NODE_EXTRA_CA_CERTS ke file ~/.zshrc kamu. Variabel ini akan otomatis dibaca oleh Node.js, npm, yarn, dan pnpm tanpa perlu ubah config cafile npm.
6. **Konfigurasi Claude Code** — Khusus Claude Code, deklarasikan environment sertifikat tersebut di file ~/.claude/settings.json agar session IDE dan subshell selalu mewarisi trust store dengan stabil.

### 2. AI Coding Agent kamu bilang 'Done!', tapi kamu panik lihat puluhan file berantakan di Git? _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Memberikan trik Git dan tools Mac praktis untuk mengaudit kode hasil buatan AI agent sebelum di-merge agar repo tetap rapi.

**Slide-by-slide:**
1. **Review Hasil Kerja AI Agent** — Saat AI coding agent selesai bekerja, tugas paling krusial buat developer adalah mereview diff kodenya. Jangan asal terima tanpa tahu apa saja yang diubah!
2. **Trik 1: Git Checkpoint Commit** — Jalankan git add -A dan buat commit checkpoint sebelum memberikan tugas ke agent. Jika hasilnya ngawur, kamu bisa langsung revert dengan git reset --hard HEAD.
3. **Trik 2: Intip Stat Dulu** — Gunakan git diff --stat untuk melihat file mana saja yang disentuh dan berapa baris yang berubah sebelum membaca detail baris demi baris.
4. **Trik 3: Cek File Baru Untracked** — AI suka meninggalkan file scratch baru. Gunakan git clean -n untuk melakukan dry-run file mana saja yang bakal dibersihkan tanpa menghapus apapun terlebih dahulu.
5. **Trik 4: Pakai Word Diff atau Delta** — Gunakan git diff --word-diff atau tool open source seperti delta agar pengubahan kata di file YAML/prose kelihatan jelas ketimbang diff standar.
6. **Trik 5: Staging Parsial** — Manfaatkan git add -p untuk memilih bagian kode yang bagus saja, dan git restore -p untuk membuang editan 'bonus' yang tidak pernah kamu minta.

**Angle:** Memperkenalkan pendekatan praktis rewrite 5% bagian bottleneck ke Rust menggunakan tool fast-anything tanpa perlu migrasi full codebase.

**Slide-by-slide:**
1. **Rewrite Total Itu Jebakan!** — Migrasi seluruh aplikasi ke Rust butuh waktu berbulan-bulan dan kompilasi yang berat. Padahal bottleneck biasanya cuma ada di sebagian kecil fungsi.
2. **Kenalan dengan fast-anything** — Tool ini memprofil aplikasi Python, Node, atau Ruby kamu, mencari fungsi paling lambat, dan memuatnya ke Rust via coding agent secara otomatis.
3. **Uji Kesamaan Otomatis** — fast-anything menguji hasil output Rust melawan recorded calls fungsi asli untuk memastikan perilakunya 100% sama pada data nyata.
4. **Aman dan Sangat Cepat** — Kalau hasil Rust tidak cocok atau malah lebih lambat dari aslinya, tool ini tidak akan mengaktifkannya. Kamu juga bisa rollback kapan saja!
5. **C-Bridge Tanpa Binding** — Berkat C-bridge berbasis JSON, bahasa seperti Ruby, Python, PHP, hingga Go bisa langsung memanggil modul Rust tanpa ribet setup headers.
