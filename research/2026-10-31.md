### 3. Web Laravel kamu mendadak lambat saat nerima request? Bisa jadi gara-gara session cleanup lottery! _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Optimasi performa request web Laravel dengan memindahkan session cleanup ke scheduler Artisan.

**Slide-by-slide:**
1. **Misteri Request yang Tersendat** — Jika aplikasi Laravel kamu memakai driver session database atau file, sesi kadaluarsa akan menumpuk. Secara default, Laravel menjalankan pembersihan sesi langsung di tengah request user secara acak.
2. **Masalah pada Session Lottery** — Opsi default lottery bernilai [2, 100], artinya ada peluang 2% setiap request pengguna tertahan untuk menjalankan query delete sebelum halaman ditampilkan. Di traffic tinggi, ini memicu query tumpang tindih.
3. **Solusi di Laravel 13.39+** — Di Laravel 13.39 ke atas, kamu bisa memanfaatkan scheduled command Artisan: session:garbage-collect. Jalankan proses pembersihan ini secara terjadwal, misalnya setiap satu jam sekali.
4. **Matikan Lottery di Config** — Setelah mendaftarkan command di scheduler, ubah konfigurasi session.php menjadi 'lottery' => [0, 100]. Sekarang, tidak ada lagi request pengguna yang terbebani query pembersihan sesi.
5. **Penanganan Multi-Server** — Bila menggunakan driver database di arsitektur multi-server, tambahkan chaining onOneServer() agar command tidak dieksekusi ganda. Untuk driver file, jalankan di masing-masing server.

### 1. Bikin garis lengkung penghubung UI dinamis di CSS kini gak perlu clip-path yang ribet! _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Tutorial teknis styling modern menggunakan properti CSS border-shape untuk visualisasi konektor UI yang fleksibel.

**Slide-by-slide:**
1. **Kelemahan clip-path Selama Ini** — Membuat garis atau bentuk kurva yang dinamis antar elemen sering kali memakai clip-path. Sayangnya, clip-path memotong seluruh elemen termasuk border dan shadow, sehingga styling garis tepi jadi sangat rumit.
2. **Kenalan dengan border-shape** — Hadir fitur modern CSS yaitu border-shape. Properti ini memungkinkan kita membentuk geometri elemen secara fleksibel namun tetap mempertahankan dekorasi seperti border-width, warna garis, dan shadow.
3. **Kombinasi dengan shape()** — Dengan memadukan border-shape bersama fungsi shape(), kamu bisa menggambar jalur garis kurva yang menghubungkan dua koordinat, lalu cukup atur ketebalan serta warna lewat properti border biasa.
4. **Trik Pseudo-element & Padding-box** — Agar kurva tidak melebar saat ukuran kontainer mengecil ke 0px, pindahkan border-shape ke pseudo-element. Pasang inset negatif dan ubah referensi ke padding-box agar garis menempel tepat di titik pusat.
5. **Dukungan Browser** — Saat ini border-shape sudah berjalan penuh di Chrome dan Edge. Coba bereksperimen di local workspace kamu untuk membuat konektor visual atau diagram interaktif masa depan!
