### 4. Penasaran apa yang sebenarnya terjadi di balik layar saat upload file berukuran gigabyte dan membuat link download? _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Mengirim file besar bukan sekadar klik upload. Arsitektur modern melibatkan chunking, resumable upload, hingga object storage.

**Slide-by-slide:**
1. **Batasan Klasik Email** — SMTP dan encoding Base64 membuat email dibatasi ukuran sekitar 25 MB karena proses konversi data menambah ukuran file hingga 33%.
2. **Arsitektur Decoupled Layanan File** — Sistem modern memisahkan client, upload server, object storage, metadata database, dan download server agar bisa diskalakan tak terbatas.
3. **Strategi Chunked Uploads** — File besar dipecah jadi bagian kecil misal 10 MB agar bisa diunggah secara paralel dan mencegah kegagalan total saat jaringan terputus.
4. **Resumable Uploads & Checksums** — Jika koneksi drop di tengah jalan, klien bisa meminta upload offset untuk melanjutkan dari posisi terakhir tanpa mengulang dari nol.
