**Slide-by-slide:**
1. **Waspada Ekstensi VSCode Berbahaya** — Ekstensi Visual Studio Code bisa sangat membantu, tapi juga bisa jadi pintu masuk malware. Modus penipuan makin canggih, yuk pelajari cara menghindarinya!
2. **Bagaimana Ekstensi Berbahaya Bekerja?** — Ekstensi palsu sering menyamar sebagai ekstensi populer, mencuri data sensitif, menyuntikkan kode berbahaya, atau bahkan menginstal malware ke sistem kamu. Ini ancaman serius bagi keamanan developer.
3. **Tanda-Tanda Mencurigakan** — Perhatikan rating yang terlalu sedikit, ulasan yang aneh atau generik, tanggal publikasi yang baru untuk ekstensi 'populer', dan izin yang diminta tidak wajar. Selalu curiga pada hal-hal ini.
4. **Lakukan Verifikasi Ekstensi** — Selalu cek nama publisher, popularitas (jumlah download), dan ulasan dari pengguna lain. Cari tahu apakah publisher punya reputasi baik di komunitas developer.
5. **Cek Izin yang Diminta** — Sebelum instal, perhatikan izin apa saja yang diminta ekstensi. Apakah ekstensi linting code butuh akses ke file sistem atau jaringan? Jika terasa tidak relevan, batalkan instalasi.
6. **Jaga Keamanan Lingkungan Kerjamu** — Pastikan VSCode kamu selalu terupdate. Gunakan antivirus dan firewall. Jangan ragu mencopot ekstensi yang mencurigakan. Keamanan adalah tanggung jawab kita bersama!

### 2. Container Queries Beda dari Media Queries, Lho! _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Penjelasan mendalam tentang perbedaan mendasar antara CSS Container Queries dan Media Queries, serta kapan harus menggunakan masing-masing untuk desain responsif yang lebih baik.

**Slide-by-slide:**
1. **Container Queries BUKAN Media Queries** — Sering dianggap sama, tapi CSS Container Queries dan Media Queries itu beda banget! Memahami perbedaannya krusial buat kamu yang mau bikin desain responsif modern.
2. **Apa itu Media Queries?** — Media Queries menyesuaikan layout berdasarkan ukuran viewport (browser). Contohnya, layout berubah saat lebar layar ponsel atau desktop. Mereka 'melayani' website secara keseluruhan.
3. **Apa itu Container Queries?** — Container Queries menyesuaikan layout berdasarkan ukuran container induknya, BUKAN viewport. Ini artinya komponen bisa adaptif secara independen di mana pun mereka diletakkan.
4. **Kapan Pakai Media Queries?** — Gunakan Media Queries untuk mengatur layout global halaman, seperti penyesuaian header, footer, atau sidebar yang tergantung pada ukuran jendela browser secara umum.
5. **Kapan Pakai Container Queries?** — Ideal untuk komponen reusable. Misalnya, kartu produk yang tampil beda saat di sidebar (sempit) dan di halaman utama (lebar). Komponen jadi lebih fleksibel!
6. **Contoh Nyata Perbedaan** — Media Query: 'Jika lebar layar < 768px, sembunyikan sidebar'. Container Query: 'Jika lebar container kartu < 300px, ubah tata letak elemen di dalamnya jadi vertikal'.
7. **Desain Lebih Modular** — Dengan Container Queries, kamu bisa bikin komponen yang benar-benar mandiri dan 'pintar'. Ini kunci untuk sistem desain yang scalable dan mudah dipelihara. Ayo mulai terapkan!
