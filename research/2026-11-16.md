### 2. Kenapa gambar 2 MB bisa bikin tab browser pengguna kamu crash seketika karena kehabisan RAM? _(Format: Feed — carousel evergreen, tersimpan di grid & gampang ditemukan lewat search/profil)_

**Angle:** Mengedukasi web developer tentang pentingnya memisahkan validasi ukuran file byte limit dengan validasi dimensi piksel memory limit sebelum memproses pratinjau gambar di browser.

**Slide-by-slide:**
1. **Jebakan Ukuran File vs Dimensi Piksel** — Banyak pengembang web hanya memeriksa batas ukuran file dalam megabyte saat pengguna mengunggah gambar. Padahal file kecil yang terkompresi dengan baik bisa membengkak menjadi jutaan piksel saat didecode di dalam memori browser. Ukuran file adalah batasan unggah, sedangkan jumlah piksel adalah batasan RAM.
2. **Hitungan Memori RGBA 8-Bit di Browser** — Gambar berukuran 8.000 x 6.000 piksel mengandung total 48 juta piksel di dalamnya. Saat dialokasikan ke dalam buffer RGBA 8-bit, gambar tersebut membutuhkan memori sekitar 192 juta byte atau 183 MiB RAM. Angka ini belum memperhitungkan alokasi buffer dekoder dan GPU di browser.
3. **Validasi Header Sebelum Alokasi Bitmap** — Jangan langsung membaca seluruh isi file atau membuat preview penuh di kanvas. Gunakan pembaca metadata ringan untuk menguraikan header file dan memeriksa dimensi piksel terlebih dahulu. Berikan pesan kesalahan yang jelas apakah file kelebihan ukuran byte atau kelebihan batas piksel.
4. **Batasi Konkurensi & Alokasi Pratinjau** — Jika aplikasi kamu menerima banyak file referensi sekaligus, lima file aman tetap berarti lima alokasi memori besar. Jalankan dekode pratinjau sesuai kapasitas perangkat dan buat thumbnail kecil untuk tampilan aktif. Selalu validasi ulang aturan dimensi ini di sisi server untuk menghindari manipulasi request.
5. **Pembersihan Memori Setelah Digunakan** — Browser tidak selalu langsung menghapus objek gambar yang sudah tidak terpakai dari memori. Jangan lupa mencabut URL objek menggunakan URL.revokeObjectURL setelah pratinjau selesai dibuat. Jika kamu memakai ImageBitmap, panggil metode close() secara eksplisit agar slot RAM langsung terbebas.
